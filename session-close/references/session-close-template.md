- Date:
- Project or feature:
- Current stage:

## Completed
- Finished items

## In Progress

## Task Status
- Completed tasks:
- In-progress tasks:
- Blocked tasks:
- Remaining tasks:
- Active worker or batch summary:

## Decisions Logged
- Decision entries appended to `decisions.md`
- Or `No material decisions logged this session`

## Blockers and Risks
- Blocking issues
- Missing approvals
- Missing verification

## Restart Notes
- Files or artifacts to reopen first
- Commands or checks to rerun
- Important context that should not be rediscovered

## Next Steps
1. First action
2. Second action
3. Third action

If multiple features were active, repeat the same structure for each feature.
