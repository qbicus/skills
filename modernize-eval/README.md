# Modernize Eval

Purpose: evaluate an existing system and recommend a modernization path.

Use it when you want:
- migrate vs phased replacement vs rewrite assessment
- a management-ready report
- sortable modernization scores across projects

Outputs:
- modernization evaluation report
- Modernization Complexity Score
- Migration Suitability Score
- Rewrite Pressure Score

Example prompts:
- `Use $modernize-eval to assess this VB.NET ASP.NET app and recommend migrate, phased replacement, or rewrite.`
- `Use $modernize-eval to compare this .NET Core 3 project against a .NET 8 migration path and produce the three summary scores.`
- `Use $modernize-eval for project-x. If migration is recommended, we will continue with modernize-plan after approval.`
