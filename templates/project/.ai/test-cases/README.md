# Tester-facing Test Cases

Use this folder for markdown test case documents that can be handed to QA/testers.

Create one file per functionality or feature area.

Recommended file name:

```text
yyyy-mm-dd-feature-name-test-cases.md
```

Each test case file should include:

- feature/functionality name;
- scope;
- prerequisites;
- test data;
- positive test cases;
- negative/edge test cases;
- regression checks;
- expected results;
- notes for testers.
