# Testing

## Automated tests

- Add or update automated tests for new functionality, bug fixes, and behavior changes unless the user explicitly says not to.
- Prefer unit tests for business/application logic.
- Add integration tests when changes cross persistence, external APIs, queues, files, or framework boundaries.

## Tester-facing test cases

- Store tester-facing markdown test cases under `.ai/test-cases/`.
- Create or update one test case file per functionality or feature area.
- Include positive, negative/edge, and regression coverage.
