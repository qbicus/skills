# Decision

Purpose: keep a running log of important implementation decisions.

Use it when you want:
- a record of what was decided
- why it was chosen
- which alternatives were considered and rejected

Default behavior:
- append to a decision log
- preserve rationale across sessions
- avoid logging trivial mechanical edits

Example prompts:
- `Use $decision to log why we chose PostgreSQL over MSSQL for this feature.`
- `Use $decision to append today's architecture decisions for feature-x.`
