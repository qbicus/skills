# Code Review Template

Use this structure when producing a written review or a final report after automatic fixes.

## Scope
- Review target
- Constraints or assumptions

## Validated Findings
- Severity
- File reference
- Problem
- Why it matters in this codebase
- Recommended fix

If no validated findings remain, state that explicitly.

## Fixes Applied
- File references
- Behavior or risk addressed
- Tests added or updated

## Verification
- Commands run
- Results
- What was not verified

## Residual Risks
- Remaining blockers
- Follow-up items that were intentionally deferred
