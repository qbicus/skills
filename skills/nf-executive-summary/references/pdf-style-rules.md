# Executive Summary PDF Style Rules

These rules govern the optional PDF generated by `nf-executive-summary`.

## Branding source precedence

1. Explicit reference PDF supplied for the current run.
2. `<repo>/.ai/templates/executive-summary/reference.pdf`.
3. `~/.ai/templates/executive-summary/reference.pdf`.
4. `../assets/standard-style.json`.

Reference PDFs are visual references only. Never modify them.

## What may be derived from a reference PDF

- page size and orientation;
- approximate margins and content width;
- dominant, accent, text, muted, rule, and background colors;
- logo/brand-mark imagery when it can be safely reused as an image asset;
- heading/body typography characteristics (family name if detectable, relative size, weight, line spacing);
- header/footer treatment;
- page numbering treatment;
- table, callout, divider, and spacing conventions.

Do not infer or reproduce hidden document content. Do not extract or redistribute embedded font files.

## Cache contract

Current cache schema version: `1`.

A valid cache must include at least:

```json
{
  "schemaVersion": 1,
  "sourcePdf": ".../reference.pdf",
  "sourceSha256": "<hex>",
  "extractedAtUtc": "<ISO-8601>",
  "style": {},
  "fontSubstitutions": []
}
```

Cached image assets may be stored beside the JSON under `assets/` and referenced by relative path.

Cache reuse is permitted only when:

- `schemaVersion` is current;
- `sourceSha256` equals the freshly computed SHA-256 of the resolved reference PDF;
- the cached source corresponds to the currently resolved reference;
- all required cached assets still exist.

Otherwise discard/rebuild the derived cache before PDF generation.

## Font policy

- Record/reference font names only.
- Use a locally installed matching font when available.
- Otherwise use a safe substitute.
- Preserve hierarchy and spacing rather than forcing a visually incompatible typeface.
- Never extract or redistribute font binaries from a PDF.

## Verification

After generating the PDF, render it and inspect the pages. Check:

- no clipped/overlapping text;
- no broken glyphs;
- readable contrast;
- correct logo scale/aspect ratio;
- sensible page breaks;
- stable headers/footers;
- content parity with `executive-summary.md`.
