# Session Close

Purpose: close a work session without losing context.

Use it when you want:
- a short session summary
- blockers and next steps recorded
- important decisions appended through `decision`

Default behavior:
- writes restart-friendly notes
- highlights incomplete work and missing verification
- can summarize multiple active features and their task status in one close-out
- captures parallel worker or batch state when parallel execution was active

Example prompts:
- `Use $session-close for customer-import and capture what we finished, blockers, and next steps.`
- `Use $session-close to summarize today's work and append any important decisions to the log.`
- `Use $session-close to summarize today's work across customer-import and billing-sync, including completed, in-progress, blocked, and remaining tasks for each feature.`
