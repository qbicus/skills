# NF Avalonia

Purpose: add Avalonia-specific guidance inside the `new-feature` workflow.

Use it when the feature includes:
- Avalonia UI
- cross-platform desktop UI
- XAML views and MVVM/viewmodels
- desktop dialogs, windows, styling, or platform adapters

Default behavior:
- support `nf-spec`, `nf-design`, `nf-tasks`, and execution
- do not replace the main `new-feature` approval chain

Example prompts:
- `Use $nf-avalonia while planning this Avalonia cross-platform desktop feature inside new-feature.`
- `Use $nf-avalonia to guide the design for this Avalonia window, dialog, and MVVM flow.`
