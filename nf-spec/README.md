# NF Spec

Purpose: create the specification-stage artifact for `new-feature`.

Use it when you want:
- implementation-ready feature requirements
- data model and contract definition
- validation, error, phasing, and scope definition

Default behavior:
- follows the fixed section structure
- records parallel-execution preference when relevant

Example prompts:
- `Use $nf-spec to write the feature spec for customer-import.`
- `Use $nf-spec to revise _localnotes/customer-import/specs.md with these review comments before approval.`
